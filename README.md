# Bon anniversaire Yaya

Page d'anniversaire animée (parchemin, portrait à l'encre, voyage à Prague).

## Mise en ligne sur GitHub Pages
1. Crée un nouveau dépôt sur GitHub (ex. `anniversaire-yaya`).
2. **Add file → Upload files**, glisse tous les fichiers de ce dossier (à la racine du dépôt), puis **Commit changes**.
3. **Settings → Pages** → Source : *Deploy from a branch* → Branch : `main` / `(root)` → **Save**.
4. Après 1 à 2 minutes, la page est en ligne sur `https://<ton-pseudo>.github.io/anniversaire-yaya/`.
